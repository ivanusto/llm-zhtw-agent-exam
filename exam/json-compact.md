# JSON 緊湊度十輪

這題不量正確率，量的是**格式紀律**：模型在被明確要求「不要有任何其他文字」之後，
會不會自作主張加換行與縮排。在 agent 迴圈裡每一次工具呼叫都要付這些 token。

## 提示詞

```
只輸出一個 JSON 物件，不要有任何其他文字、說明或程式碼區塊標記。
物件需包含 host、status、latency_ms 三個欄位，
值分別為 "nas-01"、"online"、23。
```

## 判準

十輪重複，每輪記三件事：

1. **緊湊或多行**：抽出的 JSON 物件本身含換行就算 pretty-print
2. **欄位正確**：三個欄位的值都對
3. **輸出字元數**：去掉前後空白後的長度，含 markdown 圍籬也算，
   因為在 agent 迴圈裡那些字元一樣要付 token

## 這題不能用貪婪解碼

`temperature=0` 下十輪必然一模一樣，比數只會是 0/10 或 10/10，
量不出格式偏好的分佈。預設用各家 instruct 模式的建議取樣，
腳本會把取樣設定寫進輸出的 JSON。

**引用比數時一定要連取樣設定一起報**，否則跨模型的數字無法比較。
