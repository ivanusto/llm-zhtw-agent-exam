# 繁體中文 agent 能力小考卷

這是一份極輕量、完全自動化驗證的評測工具，用來快速檢查本機模型是否具備在繁體中文環境擔任 Agent 的基本資格。不需要人工評分，也不需要另一個模型當裁判。四個項目：

| 項目 | 量什麼 | 滿分 |
|---|---|---|
| [繁中十題](exam/zh10.md) | 答得對，而且不吐簡體字 | 20 |
| [工具呼叫十輪](exam/tools.md) | 吐得出合法且欄位型別正確的 JSON | 10 |
| [多步 agent 三題](exam/agent.md) | 工具呼叫的順序對不對 | 3 |
| [JSON 緊湊度十輪](exam/json-compact.md) | 被要求「不要有其他文字」之後守不守規矩 | 比數 |

## 設計初衷

多數公開基準偏向衡量英文能力上限，這份測試只聚焦在兩件事，繁體中文可用性與 AI Agent 規矩。

英文分數再高的模型，只要輸出繁中時夾帶簡體字、或思考過程汙染輸出，在台灣的產品環境就比較不好被使用。此外，正確率高的模型不一定懂得節省 Token，JSON 緊湊度就是用最低成本快速檢視模型是否守規矩。

## 評測極限

現行主流模型通常能在前三項拿到滿分，因此這份測試只能篩掉明顯不合格的模型，無法評鑑高下。

真正具有鑑別度的是第四項 JSON 緊湊度。實測同級距模型在該項目會出現極大落差，且表現與推理正確率無直接關聯。詳細測試記錄與除錯過程請見實測數字在 [results/day14.md](results/day14.md)，裡面也記錄了一個打分數 bug 的除錯過程，
那個 bug 讓三款模型都被誤扣了一分。

## 怎麼跑

環境僅需 Python 標準函式庫，並支援任何相容 OpenAI `/v1/chat/completions` s 的端點

```bash
python3 scripts/exam.py         http://127.0.0.1:8000 <model> <label>
python3 scripts/json-compact.py http://127.0.0.1:8000 <model> <label>
```

執行細節與兩個地雷（關思考模式的開關名稱、以及為什麼 JSON 那題不能用貪婪解碼）
寫在 [scripts/README.md](scripts/README.md)。
